# 📐 カメラ台形補正シミュレーター

斜め撮影映像を **真上から見た映像（俯瞰視点）** にリアルタイム変換するWebツールです。  
**WebGL は使用せず、Canvas 2D API のみで実装**しています。

---

## ✅ 実装済み機能

| 機能 | 説明 |
|------|------|
| カメラ選択 | PC・スマートフォンに接続されているカメラを一覧表示して選択 |
| リアルタイム台形補正 | Canvas 2D の水平スキャンライン分割法でリアルタイム変換 |
| 上辺幅スライダー | 10〜300% の範囲で調整（100%=変形なし） |
| 垂直オフセット | 映像の垂直方向シフト（-50〜+50%） |
| 水平オフセット | 映像の水平方向シフト（-50〜+50%） |
| 台形プレビュー | SVGで変形形状をリアルタイム可視化（折りたたみ） |
| グリッド表示 | 変換後映像にガイドグリッドを重ねて表示 |
| 台形輪郭表示 | 変換前の台形の切り取り範囲を重ねて確認 |
| 描画品質選択 | スキャンライン数を 60 / 120 / 240 本で切替 |
| 16:9 固定表示 | 出力エリアは常にアスペクト比 16:9 を維持 |
| FPS・解像度表示 | 情報バーでリアルタイム確認 |
| スクリーンショット保存 | PNG 形式でダウンロード |
| デバイスの動的検出 | カメラの接続・切断を自動で検出 |
| レスポンシブ対応 | PC・タブレット・スマートフォンで動作 |

## 🔧 技術仕様

### 変換アルゴリズム（水平スキャンライン分割法）

```
出力キャンバスを N 本の水平スライスに分割
  ↓
各スライスの y 位置に対応する入力台形の「左端 x・幅」を線形補間で計算
  ↓
ctx.drawImage() で入力側の台形スライスを出力側の長方形スライスに引き伸ばして描画
  ↓
N 本分繰り返すと、台形全体が長方形に変換された映像が完成
```

### 上辺幅の意味

| 設定値 | 入力形状 | 効果 |
|--------|----------|------|
| 100%   | 長方形   | 変形なし |
| 50%    | 台形（上が狭い） | 奥行きを俯瞰補正 |
| 200%   | 逆台形（上が広い） | 仰角方向の補正 |

### 描画品質

| 品質 | スキャンライン数 | 特徴 |
|------|-----------------|------|
| 低   | 60 本 | 高フレームレート優先 |
| 標準 | 120 本 | バランス型（推奨） |
| 高   | 240 本 | 高品質・低速PCでは重い |

## 🚀 使い方

1. HTTPS または localhost でページを開く（getUserMedia の要件）
2. カメラを選択して「▶ 開始」
3. **上辺の幅** スライダーを小さくすると、奥行き感を補正して俯瞰視点に変換
4. 垂直・水平オフセットで映像の位置を微調整
