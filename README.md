# 📐 カメラ台形補正シミュレーター

斜め撮影映像を **真上から見た映像（俯瞰視点）** にリアルタイム変換するWebツールです。

---

## ✅ 実装済み機能

| 機能 | 説明 |
|------|------|
| カメラ選択 | PC・スマートフォンに接続されているカメラデバイスを一覧表示して選択 |
| リアルタイム台形補正 | WebGL を使った射影変換（ホモグラフィ）でリアルタイム変換 |
| 上辺幅スライダー | 10〜300% の範囲でスライダーまたは数値入力で調整 |
| 垂直オフセット | 射影変換の垂直方向のシフト調整（-50〜+50%） |
| 水平オフセット | 射影変換の水平方向のシフト調整（-50〜+50%） |
| 台形プレビュー | 設定値に応じてリアルタイムで変形形状を可視化（SVG） |
| グリッド表示 | 変換後映像にガイドグリッドを重ねて表示 |
| 原映像輪郭表示 | 変換前の台形輪郭を重ねて確認 |
| 補間方式切替 | バイリニア補間 / 最近傍補間 を選択可能 |
| 16:9 固定表示 | 出力エリアは常にアスペクト比 16:9 を維持 |
| FPS・解像度表示 | 情報バーでリアルタイム確認 |
| デバイスの動的検出 | デバイスの接続・切断を自動で検出 |
| レスポンシブ対応 | PC・タブレット・スマートフォンで動作 |

## 🗂 ファイル構成

```
index.html          メインページ（UI構造）
css/
  style.css         スタイルシート（ダークテーマ）
js/
  homography.js     射影変換行列の計算（ガウス消去法による4点ホモグラフィ）
  renderer.js       WebGL レンダラー（逆マッピング・フラグメントシェーダ）
  app.js            アプリケーション本体（カメラ・UI・描画ループ）
```

---

## 🔧 技術仕様

### 変換アルゴリズム
- **射影変換（ホモグラフィ）**: 4点対応から 3×3 変換行列を計算
- **逆マッピング**: 出力ピクセル → 入力テクスチャ座標を逆変換行列で算出（アーティファクト最小化）
- **WebGL フラグメントシェーダ**: GPU上でピクセルごとにリアルタイム変換
- **バイリニア補間**: WebGL `texture2D` によるスムーズな補間（標準）

### 上辺幅の意味
```
100% → 上辺=下辺 → 変形なし（矩形）
 50% → 上辺が下辺の半分 → 台形（奥が小さい）
200% → 上辺が下辺の2倍 → 逆台形（奥が大きい）
```

## 🚀 使い方

1. ブラウザでページを開く（HTTPS または localhost が必要）
2. 「カメラを選択」ドロップダウンでカメラを選択
3. 「▶ 開始」ボタンを押す
4. **上辺の幅** スライダーを動かして台形補正を調整
5. 必要に応じて垂直・水平オフセットで微調整
